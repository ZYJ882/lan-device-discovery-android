# 局域网设备发现 v2.3.3

发布日期：2026-08-26

## 界面调整

主页网络卡片现在只保留普通用户可直接理解的信息：IPv4、网关、连接状态、可发现设备数和可执行操作。子网 CIDR 不再直接显示在主页卡片中。

CIDR、子网掩码、IPv6、DNS、网络接口、互联网状态与发现资格仍完整保留在“网络详情”弹窗中，供需要排查网络问题的用户查看。此调整不改变网络识别、热点发现、设备发现或多网络独立扫描的实现。
