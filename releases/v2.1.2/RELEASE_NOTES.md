# 局域网设备发现 v2.1.2

发布日期：2026-08-26

## 界面与交互修复

本版本修正了 v2.1.1 在无可扫描 Wi‑Fi 或热点局域网时的主页操作层级问题。

| 项目 | 修复后行为 |
|---|---|
| 设备扫描入口 | “开始发现设备”在所有网络状态下保持可见，不再因无可扫描局域网而从首页消失。若当前仍没有可扫描网络，点击后不会伪造外部设备，并会提示可用网络状态。 |
| 本机信息 | 无可扫描网络时，本机 IPv4、接口和 CIDR 以设备列表中的“本机设备”展示，不再占据首页的主操作区域。 |
| 本机端口检测 | 端口检测移入“本机设备”详情页，作为该设备的受限操作。它只检查当前显示的本机 IPv4 的固定 14 个常见 TCP 服务端口。 |
| 详情收敛 | “本机设备”不显示不适用的型号识别与在线监测区块；普通发现设备的详情功能保持不变。 |
| 发现边界 | 首页对外部设备仍只收集 IP 与公开服务证据，不进行子网端口扫描。 |
