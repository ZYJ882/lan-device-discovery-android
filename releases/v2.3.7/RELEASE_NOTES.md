# 局域网设备发现 v2.3.7

发布日期：2026-11-17

## 本版重点：深色模式适配与详情复制

本版不改变应用的只读与隐私边界（仍不扫描端口、不上传 MAC / IP / 扫描结果），集中修复深色模式下的显示问题，并为设备详情增加整行点按复制能力。

## 深色模式修复

### 系统栏与窗口

| 问题 | 修复 |
|---|---|
| 系统深色模式下，状态栏与导航栏仍为浅色（#F7F9FC）且图标为深色，与页面深色背景（#101720）割裂 | 新增 `values-night/themes.xml`：状态栏 / 导航栏改为 #101720，图标切换为浅色（`windowLightStatusBar=false`、`windowLightNavigationBar=false`） |
| 浅色模式未声明导航栏图标颜色 | `values/themes.xml` 补充 `windowLightNavigationBar=true`（API 26 自动忽略，不影响兼容性） |
| 深色模式下对话框底色取 Material 3 默认灰色（偏暖灰），与整体蓝黑调不统一 | `darkColorScheme` 显式设置 `surfaceContainer` / `surfaceContainerHigh` / `surfaceContainerHighest`（#18232F / #1B2734 / #20313F），对话框与卡片同一色调 |

### 界面元素（新增 7 组深 / 浅自适应语义色）

修复前，以下元素在深色模式下仍使用浅色背景，部分前景文字在深色主题下接近白色，与浅色背景叠加后不可读：

| 元素 | 修复前（深色模式实际表现） | 修复后深色配色 |
|---|---|---|
| 移动网络类型角标 | 浅紫底 #F1EBFF + 近白文字，不可读 | 深紫底 #2B2543 |
| VPN 类型角标、型号识别“仅识别设备类别 / 需要 ONVIF 凭据”横幅 | 浅橙底 #FFF4E5，突兀刺眼 | 深琥珀底 #3A2E12 + 浅琥珀字 #E9C274 |
| “已存在”状态徽标、型号识别“未能确认型号”横幅、OUI 同步失败提示 | 浅红底 #FFF1F0，突兀刺眼；同步失败深红字在深色对话框内对比度不足 | 深红底 #3C1D1A + 浅红字 #F3B8B4 |
| 设备卡片“公开型号”小标签 | 浅绿底 #E8F5EE + 深色模式下浅绿文字 #75DAB2，不可读 | 深绿底 #153C32 |
| 设备公开服务标签、型号识别中性横幅 | 浅蓝灰底 #F1F5FB + 近白文字，不可读 | 深蓝灰底 #20313F |

深色与浅色两套配色均在对应背景下保持足够对比度；浅色模式外观与 v2.3.6 保持一致。

## 设备详情点按复制

- 设备详情（及网络详情）中的**任意一行**均可点按：整行写入系统剪贴板，并以 Toast 提示“已复制：<字段名>”。
- 每行右侧增加浅色复制图标，提示该行可交互；多值字段（多 IP、DNS 列表）按原样（含换行）复制。
- 对话框顶部增加“点按任意一行可复制该行内容”说明，保证功能可发现。
- 复制仅调用本机系统剪贴板，不涉及任何读取或上传行为；应用本身仍不申请剪贴板读取权限。
