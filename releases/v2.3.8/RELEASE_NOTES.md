# 局域网设备发现 v2.3.8

发布日期：2026-11-17

## 本版重点：显示信息优化

本版不改变应用的只读与隐私边界（仍不扫描端口、不上传 MAC / IP / 扫描结果），集中优化界面上呈现的扫描信息：进度更直观、设备证据更完整、详情字段排列更有条理。

## 扫描进度显示

| 改进 | 说明 |
|---|---|
| 进度百分比 | 扫描进行时，进度文本由「阶段 · 已完成/总数」升级为「阶段 · 已完成/总数（XX%）」，一眼可知剩余工作量 |
| 真实进度条 | 进度条由无限循环样式改为按完成比例填充；扫描准备阶段（总数未知）仍保持循环样式 |

## 设备列表信息增强

- 每张设备卡片新增**来源行**：显示该设备的发现方式（如「来源 ARP · mDNS · 刚刚响应」），帮助区分邻居缓存证据与主动广播证据。
- 来源行同时显示**相对响应时间**（刚刚响应 / N 分钟前响应 / N 小时前响应），反映证据新鲜程度；时间随每次扫描自动更新。
- 筛选时标题右侧计数由「N 台」升级为「匹配 X / 共 Y 台」，筛选结果数量一目了然；未筛选时仍显示「N 台」。

## 设备详情信息重排

| 改进 | 说明 |
|---|---|
| MAC 地址固定行 | MAC 地址从字段堆中提升为固定行，紧跟 IP 地址之后；其余字段不再重复显示 |
| 最后响应时间 | 新增「最后响应」行，显示完整时间（yyyy-MM-dd HH:mm:ss），便于与外部日志核对 |
| 字段语义排序 | 详情字段由字典序（ASCII 字母键全部扎堆在中文键之前）改为语义排序：发现环境 → mDNS → UPnP → SSDP → IPP → ONVIF → 名称来源；未知键排在末尾 |
| 复制提示条 | 「点按任意一行可复制该行内容」由纯文本升级为带复制图标的浅色提示条，深浅色模式下均清晰可辨（设备详情与网络详情同步更新） |

## 时间格式修正

- 「上次扫描」时间由仅显示时分（如 14:23）升级为带日期格式（如 11-17 14:23），避免跨天后产生误导。
