# 局域网设备发现 v2.1.1

发布日期：2026-08-26

## 本次更新

v2.1.1 增强了手机开启热点及无可扫描局域网时的网络可见性，同时保持首页只收集设备 IP 与公开服务证据的原则。

| 项目 | 说明 |
|---|---|
| 热点下游优先 | 枚举本机活动 IPv4 接口，识别 `softap`、`ap*`、`tether`、`rndis`、`usb` 与蓝牙共享模式接口。若已识别到共享下游接口，即使手机同时存在 Wi‑Fi 上游网络，也优先以该下游接口作为热点局域网边界。 |
| 热点 SSDP 发送 | 热点模式下将 SSDP 套接字显式绑定热点本机 IPv4，避免默认路由指向蜂窝或上游网络。 |
| 无局域网本机状态 | 未检测到可发现设备的 Wi‑Fi 或热点网络时，首页显示本机 IPv4、接口和 CIDR；该展示不触发外部设备扫描。 |
| 本机固定端口检测 | 用户可手动检查当前显示的本机 IPv4 的固定 14 个常见 TCP 服务端口。该操作不接收地址输入、不扫描外部地址或端口范围，也不发送协议载荷。 |
| 保持既有发现边界 | 首页仍不对子网执行 TCP/UDP 端口扫描；已发现设备的端口检查仍只能由详情页手动启动。 |

## 热点识别范围

普通 Android 应用无法稳定读取系统完整热点关联客户端表或 DHCP 租约。本版本继续只合并可读邻居缓存、mDNS 和 SSDP/UPnP 公开服务证据；没有发现公开服务或可读邻居记录时，不会伪造热点设备，也不代表系统设置中没有已连接客户端。
