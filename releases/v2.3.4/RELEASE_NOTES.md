# 局域网设备发现 v2.3.4

发布日期：2026-08-26

## 界面调整

设备列表中的网络归属标签现在只显示简洁网络名称，例如 `网络 · 个人热点` 或 `网络 · Wi‑Fi · 家庭网络`，不再显示子网 CIDR。

设备的实际发现子网并未删除。应用会将其单独保存为“发现子网”，只在进入设备详情后显示，供排查网络归属时查看。该字段仍直接来自用户本次点击的发现网络，不通过设备 IP 或 MAC 反向推测。
