# 局域网设备发现 v2.3.2

发布日期：2026-08-26

## 新增内容

设备列表中的每一台本次发现设备现在都会显示“网络”标记，例如 `网络 · Wi‑Fi · 家庭网络 · 192.168.1.0/24` 或 `网络 · 个人热点 · 192.168.43.0/24`。

该标记不是通过设备 IP、MAC 或接口名称反向推测，而是直接记录用户本次点击“扫描此网络”时选择的实际发现网络。因此在 Wi‑Fi、以太网和个人热点之间分别扫描时，设备条目可以明确区分来源网络；同一字段也会保留在设备详情中。
