# 局域网设备发现 v2.2.0

发布日期：2026-08-26

## 多网络主页

v2.2.0 重新实现了主页网络信息区域。网络展示和局域网扫描现在被明确分开：应用显示系统实际存在的网络，但只允许具备本地 IPv4 边界的 Wi‑Fi、以太网和个人热点成为独立扫描目标。

| 项目 | 行为 |
|---|---|
| 多网络状态 | 分别显示 Wi‑Fi、个人热点、移动网络、以太网、VPN、蓝牙与其他系统实际存在的网络；网络可用、丢失、能力变化或链路属性变化后自动刷新。 |
| 网络详情 | 点击网络卡片可查看系统实际提供的 IPv4、IPv6、网关、子网掩码、CIDR、DNS、接口、互联网状态与扫描资格。缺失字段直接隐藏。 |
| 独立扫描入口 | 每张具备扫描资格的 Wi‑Fi、以太网或热点卡片都有“扫描此网络”。扫描使用用户点击卡片对应的 `Network` / `LinkProperties`，不会把多个网段混合，也不使用移动网络或 VPN 作为局域网目标。 |
| 热点与 VPN | 热点下游接口作为独立网络显示和扫描；VPN 作为独立状态卡片显示，并明确标注通常不用于局域网设备发现。 |
| 主题 | Material 主题与主页网络卡片跟随系统深浅色设置。 |

## Android 信息边界

SSID、运营商名称、IPv6、DNS 和网络接口只在 Android 系统实际提供时显示。普通第三方应用不能稳定获得热点名称、完整热点关联客户端表、DHCP 租约或稳定 Wi‑Fi MAC；这些字段不会用“未知”占位或伪造。

设备发现算法、设备详情、按需型号识别和端口扫描边界保持不变：默认发现仍不进行子网端口扫描。
